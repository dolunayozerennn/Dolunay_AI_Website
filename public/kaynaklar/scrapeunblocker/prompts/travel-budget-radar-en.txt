## ScrapeUnblocker integration

Open the official SDK with `Client(..., max_retries=0)`; the app owns the retry policy.
Use `client.skyscanner.flights(...)` for flights. The SDK has NO other call for this product:
never invent a method name, a parameter, or a field like `rules_hint`; fallbacks use the same two calls. Supply:

- `origin`, `dest`, `depart_date`, `return_date`,
- `adults`, `cabin`, `market`, `locale`, `currency`, `max_polls`.

Never invent the response shape. A live measurement on 14 August 2026 returned these field
paths; read the names verbatim: root `itineraries`, result list `itineraries.results`, status
`itineraries.context.status`. Each result carries `legs` (outbound `legs[0]`, return `legs[1]`
when present), `legs[].origin.id` and `legs[].destination.id` (IATA), `legs[].departure` /
`legs[].arrival`, `legs[].durationInMinutes` (one-way minutes), `legs[].stopCount`,
`legs[].carriers.marketing[].name`, `price.raw` (number), `price.formatted` (string), and the
booking link `pricingOptions[0].items[0].url` (prefix a relative path with
`https://www.skyscanner.net`). Invent no other field; a result with an empty price is not a
price result.

For every route and window the first request uses the planned IATA code for `origin` and
`dest`; send exactly one IATA code per request, never a comma-joined list. Validate the first leg's airports against the expected IATA sets; a response resolved to
a different city is not a price result.

Plain-city fallback is a run-wide state machine, never Cartesian. Start
`origin_city_fallback_attempts` and `dest_city_fallback_attempts` at `0`; neither may exceed `1`.
INCREMENT the matching counter every time you use a fallback, and drive both the decision and the
repeat guard off that counter. The value reaching the manifest must reflect what actually happened;
a counter left at zero turns the report into a lie.

- Normal: `origin_IATA/dest_IATA`.
- Destination alone wrong and its counter `0`: once `origin_IATA/dest_plain_city`.
- Origin alone wrong and its counter `0`: once `origin_plain_city/dest_IATA`.
- For `404`, empty or ambiguous output, try the unused destination fallback, then origin fallback.
  The order is FIXED: loosen the destination side first, the origin second. Reversed is a bug.
- Forbid `origin_plain_city/dest_plain_city`, nested candidate loops, identical retries and any
  later city fallback on a spent side.

A `2 destinations x 2 windows` fixture test must prove the SDK call order for an ambiguous failure: first route `IATA/IATA`, `IATA/dest_plain_city`,

Code must contain one named decision gate, the `FALLBACK_TRIGGER_MATRIX` constant. `ALLOW`: only

## Error and retry contract

The SDK does NOT return these codes, it RAISES. Every one is a `ScrapeUnblockerError`;
the `APIError` branch carries `status_code` (measured on 0.1.8: `BlockedError`,
`NotFoundError`, `RateLimitError`, `AuthenticationError`, `ServerError` and siblings).
Apply the matrix below by catching those exceptions and reading `status_code`. No SDK
exception may reach the user: the run ends with one readable warning line and a report,
never a traceback. Measured, three separate builds died right here: one never caught
`BlockedError`, one called a method the SDK does not have and got `AttributeError`, one
serialized a `set` on the error path and got `TypeError`.

- `400`, `401`, `402`, `422`: key, plan or parameter error. Do not retry; stop immediately.
- `403`: source block. Do not repeat the same request.
- `404`: endpoint or result unavailable. Do not repeat the same request. Only the run-wide,
  one-per-side plain-city state machine above may run.
- `429`, network timeout, `500`, `502`, `503`, `504`: three attempts total; wait one second
  after the first failure and two after the second.
- An HTTP `200` body with a captcha, access-denied page or human verification is not success.
- For an unknown failure, never synthesize data; show the row incomplete with its reason.

Count only usable `2xx` responses as successful and billable. Track attempts, successful 2xx and cache hits
separately. Never estimate remaining credits.
