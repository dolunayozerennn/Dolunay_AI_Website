## ScrapeUnblocker routing

The first network call must be one Google Local health canary:

```python
su.google_local(keyword, proxy_country="TR", hl="tr", gl="tr")
```

Attempt this endpoint exactly once and do not retry it. When the response has a
non-empty, valid `results` array, use it as the primary discovery source. Safely read
`name`, `rating`, `reviews`, `category`, `address`, `phone`, `website`, `hours`,
`position`, and `sponsored`. Never infer a missing field.

If Google Local returns `403`, malformed JSON, or no usable results, open the fallback:

1. Use `su.serp(...)` for organic verification.
2. Use `su.get_page_source(google_search_url)` when a local pack is required.

Only process the SERP `organic` array. A valid empty array is a normal result. Fall
back to page source on malformed data, `403`, or a persistent endpoint failure. Reject
Google consent pages, traffic challenges, and bot interstitials even when HTTP is `200`.

Make the retry matrix explicit and testable:

- `401` and `402`: Stop immediately. Never retry.
- `400`, `403`, `404`, `415`, and `422`: Do not retry the same endpoint.
- `408`, `429`, `500`, `502`, `503`, and `504`: At most three total attempts.
- Connection failures and local timeouts: At most three total attempts.
- Backoff: Short exponential delays, capped at four seconds.

Open the official client with `max_retries=0`. Our code must own retry decisions so
the budget and manifest show the real number of attempts. Count every successful
`2xx` as a potentially billable request. Track rejected `2xx` challenge pages separately.

## Entity resolution

Never merge businesses using the name alone. Normalize these signals:

- Domain: Remove `www` and ports. Exclude directories and social domains.
- Phone: Accept only real phone patterns. Normalize Turkey's country code.
- Address: Remove punctuation and generic address words. Compare complete token sets.
- Name: Remove generic industry terms. Compare meaningful words.

An identical domain or phone is strong identity evidence. An identical address alone
is insufficient because unrelated companies may share a building. Require meaningful
name overlap alongside address similarity. Never treat years, prices, review counts,
or arbitrary long numbers as a phone or identity signal.

Store entity-resolution reasons. Calculate an opportunity score and a separate
confidence score. Opportunity measures potential value. Confidence measures evidence
coverage. Never present a low-confidence lead as if it were strongly verified.

## Inspection and evidence

Measure these facts when possible:

- Does the Google listing link to the business's own website?
- Does a verified domain appear on page one for the business-name search?
- Does the business appear in the main region-industry local or organic results?
- Can ScrapeUnblocker reach the website?
- Does the fetched page show a phone, form, WhatsApp link, and mobile viewport?
- Does the listed website use HTTPS?

"I did not see it" is not the same as "it does not exist." If a site cannot be
fetched, record "not measured" and make no quality claim. If viewport is absent, say
"mobile viewport was not observed," not "the site is not mobile-friendly." Do not use
the newest year printed on a page as a freshness signal. Do not parse review or price
numbers as telephone numbers.

Store each evidence record in this shape:

```json
{
  "code": "name_search",
  "claim": "The business-name search completed",
  "source_type": "serpApi",
  "source": "query or URL",
  "observed": {},
  "confidence": 90,
  "supported": true
}
```
