Claude Code ya da Codex kur

Sistem bir terminal ajaninin icinde calisir. Ikisinden biri yeter; ayni prompt ikisinde de ayni sekilde koser. Aradaki tek fark ne odedigin.

Claude Code

Aylik en az 20 dolar

Anthropic'in terminal ajani. Ucretsiz paketi yok; en dusuk abonelik ayda 20 dolar.

npm install -g @anthropic-ai/claude-code

Codex

Ucretsiz

OpenAI'in terminal ajani. Baslamak icin herhangi bir odeme yapman gerekmiyor.

npm install -g @openai/codex

AIsa'yi kurdugun ajana bagla

aisa.one adresinden hesabini ac ve AIsa baglantisini Claude Code ya da Codex'e ekle. Sistemin baktigi her sey buradan geliyor: arama hacmi, tedarikci fiyatlari, rakip sayfalari, videolar. Baglanti kurulu degilse sistem ilk adimda durur.

Bu tek baglanti yeter. Baska anahtar, baska hesap, baska kurulum istenmiyor.

3

Sekiz soruyu cevapla, sonra kiti kopyala

Prompt'un en tepesinde bir girdi blogu var. Asagiya yazdigin her cevap aninda prompt'un icine islenir: noktali satirin yerini senin cevabin alir. Kutuyu izle, prompt gozunun onunde dolar. Sistem yalnizca bu parametrelerin icinde arar; bos birakirsan durur ve sorar.


  

  

  

    
Panoyu neden bir dosya uretiyor

    
Prompt panonun nasil gorunecegini anlatir, ama her kosuda ayni panoyu
      cizdirmek prompt'un isi degil. PANO.py o isi devralir: olculen JSON'u
      okur, urun ve video gorsellerini kendi indirir, kucultur ve sayfanin
      icine gomer. Boylece pano tek dosyadir, tedarikcinin sunucusu kapansa
      bile bozulmaz ve her kosuda ayni cikar.

    
python3 PANO.py olcum.json pano.html

    
Calismasi icin gereken tek sey bilgisayarda Python olmasi. Kutuphane
      kurulmaz. Bir anahtar eksikse script daha ilk satirda adiyla soyler.
